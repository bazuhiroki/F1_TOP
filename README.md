# 🏁 F1 TOP

Notionの「F1 HQ」と相互に連携する、自分専用のF1ダッシュボード。
運用コストは **0円**（Vercel Hobby または Cloudflare Pages の無料枠 ＋ GitHub Actions ＋ 無料API）。

## できること
| 画面 | 内容 | Notion連携 |
|---|---|---|
| ホーム | 次のGP、週末5セッションをスタートシグナル5灯で表示（決勝開始で全灯消灯）、次のセッションまでのカウントダウン（日本時間）、ランキング上位、タイトル争いの残りポイント計算、推し、未読ニュース | 推し・ニュースを読み込み |
| カレンダー | 全戦の決勝時刻（日本時間）、スプリント開催、優勝者、観たかどうか | 「観た」を表示 |
| レース詳細 | 決勝・予選・スプリント結果、全セッション時刻、観戦メモ | **メモと「観た」をNotionへ保存** |
| 順位 | ドライバーズ/コンストラクターズ、ポイント推移グラフ | 推しを太線で強調 |
| **リプレイ** | 終わったレースをコース図上で再生。選んだ2台はマシン形状で実測位置を走り、他の20台も推定位置で表示。各車のハンドル計器（シフトライト・ギア・速度・回転数・アクセル/ブレーキ・Gボール・タイヤ・ウイング）、2台の差、タイヤ戦略、ラップタイム、隊列、レースコントロール表示。チームメイト対決も1タップ | 推しを初期表示 |
| ドライバー | 全ドライバーのカード | **推しをNotionへ保存** |
| ニュース | NotionのF1ニュース・アーカイブ（未読/すべて） | **既読をNotionへ保存** |
| 用語 | Notionの用語集を検索・カテゴリ絞り込み | 読み込み |

スマホではホーム画面に追加するとアプリのように使えます。

## 仕組み
```
[Jolpica-F1 API] ──(毎日/レース週末は2時間おき)──> GitHub Actions ──> [Notion F1 HQ]
       │                                                                  ▲  │
       └──> Cloudflare Pages Functions /api/f1 (キャッシュ中継)            │  │
                         │                     /api/notion (読み込み) ─────┘  │
                         ▼                     /api/update (書き戻し) ────────┘
                  Webアプリ（web/）
```
- Notionのトークンは Cloudflare と GitHub の「シークレット」にだけ置き、リポジトリやブラウザには出しません。
- Notionのデータを見る/書くには「合言葉」（APP_KEY）が必要です。URLを知られても推しやメモは見られません。
- アプリから書き換えられるのは「推し」「観た」「観戦メモ」「既読」だけに制限しています。

## ファイル構成
```
web/                     Webアプリ本体（HTML/CSS/JS、ビルド不要）
web/replay.js            レースリプレイ（コース図・マシン描画・計器）
api/                     Vercel のサーバー関数（中身は functions/ と共通）
functions/api/           Cloudflare Pages のサーバー関数
lib/notion.js            Notion API の共通処理
sync/sync_f1.py          Jolpica → Notion 同期スクリプト
.github/workflows/       同期の自動実行
docs/SETUP.md            セットアップ手順（初回だけ）
docs/F1_API.md           F1データAPIのリンク集
```

データ提供:
- [Jolpica-F1](https://github.com/jolpica/jolpica-f1)（順位・結果・カレンダー、有志運営・寄付制）
- [TracingInsights/2026](https://github.com/TracingInsights/2026)（リプレイ用テレメトリ、FastF1由来、Apache-2.0）。ブラウザがGitHubから直接読み込むため、こちらのサーバー負荷・費用はかかりません
